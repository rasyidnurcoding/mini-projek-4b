di program ini kami memudahkan pengguna dalam mencari total kondisi kelas SD yang ada di dataset menjadi program, program ini  dimulai dengan login sebagai pengguna(Mahasiswa, Dosen, Masyarakat Umum) lalu masuk ke bagian menu:

1. Menu Peringatan Kerusakan = Menu ini menampilkan pilihan provinsi, pengguna diarahkan untuk memilih salah satu provinsi, lalu program akan memproses serta menampilkan kondisi ruang kelas berdasarkan statusnya yaitu(ringan, kritis, perlu perhatian)
2. Menu Perbandingan 2 Provinsi =  Menu ini menampilkan perbandingan  antara 2 provinsi yang dipilih pengguna
3. Menu Anggaran =  Menu ini menampilkan seluruh provinsi lalu pengguna akan menginput anggaran sesuai dataset.
4. Keluar = Program selesai
